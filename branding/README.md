# Voiceling logo kit

**The idea:** the Deskling companion's head is a speech bubble. Voiceling is Deskling's voice.

Built from Deskling's exact shapes on its 72 × 64 grid: the 58 × 42 head with 16-unit corners, the pill eyes, and the off-centre antenna at 57°. The speech-bubble tail mirrors the antenna through the centre of the head, on the same angle. PNG sizes, favicons and the menu bar renders are generated from these masters.

## Which file to use

| Need | File |
| --- | --- |
| App icon (primary) | `voiceling-app-icon.svg`, `Voiceling/Assets.xcassets/AppIcon.appiconset`: dark tile, lime mark |
| App icon (alternate) | `voiceling-app-icon-lime.svg`: lime tile, dark mark, for the website, social posts or anywhere lime reads better |
| Mark on its own | `voiceling-mark-{black,white,lime,ink}.svg` |
| Mark at 32 px or smaller | `voiceling-mark-small-*.svg`: heavier antenna and eyes so they survive tiny sizes |
| Name + mark | `voiceling-lockup-{black,white,on-dark}.svg` (text converted to outlines, no font needed) |

| Role | Hex |

## Rules

- The eyes are cut-outs, so the background shows through them. Don't fill them with a colour.
- Keep clear space of one eye-height (about 0.3 of the head's height) around the mark.
- Use the small master under 48 px. Below 16 px, use the app icon rather than the bare mark.
- Wordmark: Nunito Sans ExtraBold, lowercase, tracked −2%, the same as Deskling's. In the lockup, the head sits on the baseline at cap height, the antenna rises like an ascender, and the tail drops like the "g".
- Don't recolour the antenna separately, add gradients, rotate the mark, or swap the tail to the other side.
